<h3 class="font-headline-md text-headline-md mb-md flex items-center gap-sm">
<span class="material-symbols-outlined text-primary">description</span>
                            Description
                        </h3>
<p class="font-body-md text-body-md text-on-surface-variant mb-md leading-relaxed">
                            A critical vulnerability has been identified in the core authentication service that allows unauthenticated attackers to execute arbitrary code on the host system. The flaw exists in the deserialization process of incoming JWT tokens within the legacy auth-v1 endpoint.
                        </p>
<p class="font-body-md text-body-md text-on-surface-variant leading-relaxed">
                            Exploitation requires sending a specially crafted serialized payload in the Authorization header. Successful exploitation grants the attacker the same privileges as the application service account, which may lead to full system compromise if not properly sandboxed.
                        </p>
</div>
