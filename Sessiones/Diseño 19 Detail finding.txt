<!-- Description -->
<section class="glass-card rounded-xl p-lg">
<h2 class="font-headline-md text-headline-md text-on-surface flex items-center mb-4 border-b border-outline-variant/30 pb-2">
<span class="material-symbols-outlined mr-2 text-primary">description</span>
                        Descripción Técnica
                    </h2>
<p class="font-body-md text-body-md text-on-surface-variant leading-relaxed mb-4">
                        Se identificó una vulnerabilidad de Inyección SQL (SQLi) basada en errores en el parámetro <code class="font-mono-md bg-surface-container px-1 py-0.5 rounded border border-outline-variant/50">username</code> del endpoint de inicio de sesión (<code class="font-mono-md bg-surface-container px-1 py-0.5 rounded border border-outline-variant/50">/api/v1/auth/login</code>). La falta de sanitización adecuada en la entrada del usuario permite a un atacante no autenticado inyectar consultas SQL arbitrarias directamente en el motor de la base de datos PostgreSQL subyacente.
                    </p>
</section>
<!-- Proof of Concept -->
<section class="glass-card rounded-xl p-lg">
<h2 class="font-headline-md text-headline-md text-on-surface flex items-center mb-4 border-b border-outline-variant/30 pb-2">
<span class="material-symbols-outlined mr-2 text-primary">bug_report</span>
                        Prueba de Concepto (PoC)
                    </h2>
<p class="font-body-md text-body-md text-on-surface-variant mb-3">La siguiente solicitud HTTP demuestra la extracción exitosa de la versión de la base de datos:</p>
<div class="bg-inverse-surface text-inverse-on-surface rounded-lg p-4 overflow-x-auto relative shadow-inner">
<div class="absolute top-2 right-2 text-outline text-xs font-mono-md">HTTP Request</div>
<pre class="font-mono-md text-mono-md">POST /api/v1/auth/login HTTP/1.1
Host: api.enterprise-target.com
Content-Type: application/json

{
    "username": "admin' OR 1=CAST((SELECT version()) AS int)--",
    "password": "Password123!"
}</pre>
</div>
</section>
<!-- Remediation -->
<section class="glass-card rounded-xl p-lg border-l-4 border-l-tertiary">
<h2 class="font-headline-md text-headline-md text-on-surface flex items-center mb-4 border-b border-outline-variant/30 pb-2">
<span class="material-symbols-outlined mr-2 text-tertiary">build</span>
                        Pasos de Remediación
                    </h2>
<ol class="list-decimal list-inside font-body-md text-body-md text-on-surface-variant space-y-3">
<li><strong>Implementar Consultas Preparadas (Parameterized Queries):</strong> Evitar la concatenación dinámica de cadenas. Utilizar frameworks ORM o bibliotecas de base de datos que manejen la parametrización de forma nativa.</li>
<li><strong>Validación de Entrada:</strong> Aplicar una lista blanca estricta (allowlist) para los caracteres permitidos en el campo <code class="font-mono-md">username</code>.</li>
<li><strong>Principio de Mínimo Privilegio:</strong> Asegurar que la cuenta de la aplicación que se conecta a la base de datos solo tenga permisos de lectura/escritura en las tablas estrictamente necesarias, denegando accesos a esquemas del sistema.</li>
</ol>
<div class="mt-4 bg-surface-container p-4 rounded-lg border border-outline-variant/50">
<h4 class="font-label-md text-label-md text-on-surface mb-2">Ejemplo de Código Corregido (Node.js/pg):</h4>
<pre class="font-mono-md text-mono-md text-sm text-on-surface-variant overflow-x-auto">// Vulnerable:
// const query = `SELECT * FROM users WHERE username = '${req.body.username}'`;

// Corregido:
const query = 'SELECT * FROM users WHERE username = $1';
const values = [req.body.username];
const res = await db.query(query, values);
</pre>
</div>

                    </h2>
<p class="font-body-md text-body-md text-on-surface-variant">
