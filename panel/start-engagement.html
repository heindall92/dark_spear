  1. En una terminal: cd /home/kali/dark_spear/panel && python3 server.py

    Uso de tokens de IA

    El agente ReAct llama a Ollama Cloud en cada paso. Eso consume tokens (y puede agotar la cuota o generar coste según tu plan).

    • Cada decisión del agente (herramienta / hallazgo) es una petición al modelo.
    • El historial del engagement se reenvía; el gasto crece con la duración del análisis.
    • Sin IA puedes usar solo el playbook (OSINT + fases) sin consumir tokens.
